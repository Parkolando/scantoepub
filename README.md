# Scan to EPUB

깔끔하게 파괴식 스캔한 PDF를 판매용 전자책에 가까운 EPUB으로 변환하는 데스크톱 앱.

## 목표

- 본문, 제목, 목록은 OCR해 재배치 가능한 XHTML로 만든다.
- 표는 신뢰도가 충분하면 HTML 표로 만든다.
- 사진, 삽화, 수식, 복잡한 레이아웃은 원본 PDF에서 잘라 이미지로 보존한다.
- 페이지별 결과를 미리 보고 수정한 뒤 EPUB으로 내보낸다.

## 최소 변환 흐름

1. PDF 페이지를 이미지로 렌더링한다.
2. OpenAI 호환 멀티모달 API에 페이지 이미지를 보내 구조화된 JSON을 받는다.
3. JSON의 읽기 순서, 블록 종류, 좌표, 텍스트를 검증한다.
4. 이미지 블록은 원본 렌더링에서 로컬로 잘라낸다.
5. XHTML, CSS, 목차, 메타데이터를 묶어 EPUB 3 파일을 만든다.
6. EPUBCheck로 결과를 검증한다.

## 첫 버전 범위

- 입력: 텍스트 레이어가 없어도 되는 깔끔한 단일 PDF
- 출력: EPUB 3
- 블록: 제목, 문단, 목록, 표, 이미지, 페이지 나눔
- API: 사용자가 지정한 OpenAI 호환 엔드포인트와 모델
- 검수: 페이지별 원본/변환 결과 미리보기와 간단한 텍스트 수정

## 기술 방향

Electron + TypeScript를 우선 사용한다. EPUB 자체가 XHTML/CSS 기반이라 미리보기와 결과물 생성에 같은 웹 기술을 재사용할 수 있기 때문이다.
