# Scan to EPUB

[English](README.md) | [한국어](README.ko.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md)

きれいに裁断スキャンされた PDF を、リフロー型 EPUB 3 電子書籍として再構成する Electron アプリです。

## 機能

- 通常ページの PDF ページ境界を取り除き、本文を連続した XHTML に統合します。
- 目次、章扉、装飾レイアウト、白黒反転ページなど、再現すると品質が損なわれるページは全ページ画像として保持します。
- 写真、挿絵、数式、複雑な表を元のレンダリングから切り抜いて挿入します。
- 単純な表は安全な XHTML テーブルに変換します。
- スキャンページをまたいで続く段落を結合します。
- 失敗したページを飛ばして残りを処理し、次回は失敗または未処理のページだけを再開します。
- 指定した数のリクエストを並列処理しながら、結果を元の順序に保ちます。
- 認識されたテキストをアプリ内で直接編集できます。
- 表紙、タイトル、著者、言語、目次を含む EPUB 3 ファイルを保存します。
- UI は韓国語、英語、中国語（簡体字・繁体字）、日本語に対応しています。

## 使い方

1. `Scan-to-EPUB-0.2.0-x64-setup.exe` をインストールして起動します。
2. PDF を選択し、分析するページ範囲を指定します。
3. OpenAI 互換の `/chat/completions` URL とマルチモーダルモデル名を入力します。
4. リモート API を使う場合は API キーを入力します。認証不要のローカルサーバーでは空欄にできます。
5. ページ分析を実行し、結果を確認・修正します。
6. `EPUB を保存` を選択します。

API キーは保存されません。API URL とモデル名だけがローカルのアプリ設定に残ります。
Chat Completions が Base64 画像を拒否した場合、同じサーバーの Responses API に自動で切り替えます。
インストール版は起動時に GitHub Releases の更新を確認し、自動でダウンロードします。
書籍の言語には BCP 47 コードを入力します。韓国語は `ko`、英語は `en`、日本語は `ja`、中国語簡体字は `zh-Hans`、繁体字は `zh-Hant` を推奨します。

## 開発

```powershell
npm install
npm start
```

```powershell
npm test
npm run test:smoke
npm run dist
```

`npm run dist` は自動更新対応の NSIS インストーラーを生成します。ジェネレーターのリフロー／固定レイアウト混在サンプルは、EPUBCheck 5.3.0 でエラー・警告なしに検証されています。
